# Ateliê Marcelo Parducci

App pessoal (PWA) para o ateliê de cerâmica: laboratório de esmaltes, referências, biblioteca, caderno e calculadoras.

- React + TypeScript + Vite, instalável como PWA (offline).
- Dados locais em IndexedDB (Dexie), prontos para sincronizar com Supabase.
- `npm install` · `npm run dev` · `npm run build`
